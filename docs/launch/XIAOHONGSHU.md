## 正文（复制这一段）

这是我第一次在 GitHub 开源自己的项目，它叫「双轨记」，英文名是 2ndJot，读作 Second Jot。

起因是一个很小的困扰：正在写东西、查资料，脑子里突然冒出另一个想法。怕忘，又不想现在就顺着它往下做。

所以，我给这些想法留了另一条轨道。

按下快捷键，弹出一个小输入框。记完以后，有两个去向：

💾 回车，或点软盘——在自己的 Obsidian 库里存成一份 Markdown，之后再整理。
📌 点图钉——先留成桌面便签，等手头的事做完。便签里的修改会自动保存在本机，关闭时也可以选择另存。

可以打字，也可以用当前输入法的语音输入。语音由输入法提供，双轨记自己不录音，也不做语音识别。

界面支持中文和英文，默认跟随系统，也可以在设置里随时切换，不用重启，不改已经写下的内容。

「主线继续，灵感先记。」这也是名字和双轨 Logo 想表达的意思。

没有注册账号这一步。项目采用 MIT 许可证，免费下载，欢迎使用、修改。

目前只做 Mac，应用下载包面向 Apple Silicon（M 系列芯片）。保存 Markdown 需要选择本地 Obsidian 库；桌面便签可以独立使用。当前版本还没有经过 Apple 公证，首次打开的步骤和实测范围都写在 README 里。

## 常见评论，直接回复

- **Windows 能用吗？** 目前只有 macOS 版，暂未确定 Windows 计划。
- **必须装 Obsidian 吗？** 桌面便签可以独立用。保存 Markdown 的文件夹目前需要位于 Obsidian 库内。
- **要用微信输入法吗？** 不必须，使用你自己的输入法即可。语音能力由输入法决定。
- **有英文界面吗？** 有。设置 → 通用 → 界面语言，可选跟随系统、简体中文或 English，即时切换。已有正文、自定义提示和其他设置不变；系统对话框按 macOS 的语言显示。
- **笔记会上传吗？** 双轨记没有内置笔记上传或统计上报；输入法语音和 Obsidian 同步由它们各自控制。
- **打不开怎么办？** 先核对芯片、系统、下载来源与校验值，再按 README 的首次打开说明操作；遇到不同提示请提供截图并隐藏私人信息。
- **免费吗？** MIT 开源，可以免费下载、使用、修改和再分发，保留许可证与版权声明即可。
